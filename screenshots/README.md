# Screenshots

As imagens desta pasta apresentam o AsterTI em funcionamento, na versão 2.02.

## Origem e privacidade

- capturas feitas em uma cópia temporária e descartável da aplicação;
- banco SQLite novo e isolado, gerado por uma rotina de dados de demonstração;
- nenhum banco, upload, log ou configuração do ambiente privado foi utilizado;
- nomes, equipamentos, locais, setores, e-mails e métricas visíveis são
  fictícios;
- nenhuma credencial preenchida é mostrada.
