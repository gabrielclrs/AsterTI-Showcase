# Screenshots

As imagens desta pasta apresentam o AsterTI em funcionamento.

## Origem e privacidade

- capturas feitas em uma cópia temporária e descartável da aplicação;
- banco SQLite novo e isolado;
- dados gerados exclusivamente para demonstração;
- nenhum banco, upload, log ou configuração do ambiente privado foi utilizado;
- nomes, equipamentos, locais, setores e métricas visíveis são fictícios;
- nenhuma credencial preenchida é mostrada.
